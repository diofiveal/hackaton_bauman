# Результаты рефакторинга

Основание: загруженный `hackaton_bauman.zip`. Изменены организация и читаемость
кода. Формулы Смолвуда, знаки коэффициентов, сетка и порядок операций рекурсии
сохранены.

## Структуры данных

| Прежняя структура | Замена и основание |
|---|---|
| Два `AccelerationRecord(Protocol)` | Удалены дубликаты; используется общий `AccelerationData` |
| `CompensatedAxes`, `PreparedAcceleration` | Используется `AccelerationData`, сохраняющий время и Fs |
| `TotalAccelerationResult` | Возвращается `np.ndarray`; время уже есть во входном сигнале |
| `EventAccelerationData` | `AccelerationData`; индексы доступны через `EventFrame` |
| `FrequencyGrid` | Массив частот; метаданные источника не использовались потребителями |
| `SmallwoodCoefficientTable` | Обычный кортеж `SmallwoodCoefficients` |
| `SRS1DResult` | Массив SRS в порядке переданных вызывающим кодом частот |
| `SpectrumCSV`, `EnvelopeResult` | Общий `SRSResult` с частотами и тремя спектрами |

Классов в рабочем коде: **25 → 14**. Классы параметров сохранены: они реально
участвуют в профилях, валидации и передаче настроек. `SmallwoodState` сохранён
для явного хранения состояния и обработки блоками.

Удалены не влиявшие на выполнение поля:

- `grid.fixed`, `grid.strict_file_validation`;
- `input.columns`, `input.required_axis_channels`, `input.calculate_resultant_acceleration`;
- `calculate_each_axis_separately`, `smallwood_formulas_unchanged`, `coefficients_may_be_precomputed`;
- `valid`/`status` внутри кадров и SRS;
- дублирующие `source_start_index`/`source_end_index` промежуточного кадра;
- неиспользуемые свойства `fmin_hz`/`fmax_hz`; действующие `start_hz`/`stop_hz` сохранены.

Сторонний JSON с удалёнными ключами следует обновить. Загрузчик сообщает
о неизвестном параметре; приложенный `examples/contest.json` совместим.

## Функции и методы

- Удалены не вызывавшиеся проектом `contest_trigger_mask()`,
  `first_contest_trigger_index()`, `build_acceleration_table()`.
  Триггер выполняет используемая `detect_event_frame()`.
- Удалены неиспользуемые `cmsis_feedback()` и `as_matrix()`.
- `row()` исчез вместе с классом таблицы: перебирается кортеж коэффициентов.
- Проверки конечности и устойчивости коэффициентов остались в функции расчёта;
  вспомогательные `numerator()`, `denominator()`, `pole_magnitudes()`,
  `is_stable` больше не нужны.
- `_sin_over_argument()` заменена прямым `np.sinc` с тем же аргументом.
- Общие проверки сигналов и частот находятся в `validation.py`.
- Модуль ускорения возвращает `hypot(hypot(ax, ay), az)` подготовленных осей.
- Компенсация не выполняется повторно для расчёта модуля. Подготовленный сигнал
  используется детектором и SRS; явная политика raw-magnitude сохранена.
- `calculate_srs_xyz()` принимает конкретные параметры; `getattr(config, ...)`,
  предобработка и чтение файлов удалены из математического ядра.
- Крупные блоки CSV, metadata и графиков вынесены в короткие именованные функции.

Функции одного осциллятора и `calculate_srs_1d()` сохранены для проверки ядра
и исследовательского использования, покрыты тестами. Все четыре способа
задания сетки сохранены: они доступны через конфигурацию.

## Стиль и комплектность

- Ruff: четыре пробела, единые кавычки, переносы и сортировка импортов.
- Убраны неиспользуемые импорты и двойные блоки `try/except ImportError`.
- Добавлены `pyproject.toml`, `requirements-dev.txt` и отсутствовавшая
  зависимость `matplotlib`.
- `.bat`/`.sh` запускают существующий пример в режиме validation.
- Удалены старые неработающие тесты: один ссылался на отсутствующий CSV,
  другой импортировал отсутствующий `bin_to_csv.py`. Добавлены действующие
  тесты CSV и полного конвейера. BIN-конвертер исходным архивом не поставлялся
  и в рамках рефакторинга не создавался.
- Из выдаваемого архива исключены `.git` и кэши Python/Ruff. Входные CSV,
  сетка и пользовательские результаты `output/1..6` сохранены.

## Проверки

1. До изменений исходный код обработал пять raw-записей с двумя вариантами
   хвоста — 10 эталонных расчётов float64.
2. Дополнительно зафиксирован синтетический сигнал с подтверждённым покоем:
   оба хвоста, кадр `123..147`, `Amax=5g` — ещё 2 расчёта.
3. Все 12 таблиц `94×5` после рефакторинга совпадают **поэлементно точно**
   с исходным кодом в проверенном окружении.
4. Осциллятор сравнивается с `scipy.signal.lfilter` на нулевом, постоянном,
   импульсном, отрицательном, полусинусоидальном и знакопеременном входе:
   `atol=1e-12`, `rtol=1e-11`.
5. Проверены перенос состояния, reset, хвост, компенсация, детектор, CSV,
   сетки, overrides, огибающая, графики и CLI из другой папки.

Это проверка сохранения поведения, а не заявление о совпадении с судейским
эталоном или о достигнутой оценке конкурса.

Время и алгоритм события сохранены: время CSV не сдвигается к нулю,
коэффициенты используют измеренный Fs, детектор ищет максимум после первого
триггера. Изменение этих правил потребует отдельной задачи и новых эталонов.

Команды воспроизведения приведены в `README.md`.
